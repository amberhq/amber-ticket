# Amber ticketing platform: planning docs

This folder holds the planning documents for Amber's in-house ticketing platform, built on Zammad. Use them when writing or refining Jira tickets under epic [AI-1283](https://amberhq.atlassian.net/browse/AI-1283).

| File | What it holds |
|---|---|
| [starter-tickets-sprint-1.md](starter-tickets-sprint-1.md) | The first 6 agreed Stories, with the decisions taken while writing them. |
| [ticket-platform-tasks.md](ticket-platform-tasks.md) | The full breakdown: 116 tickets across 17 epics, grouped by P0, P1 and P2. |

Source material:

- [AI-1284](https://amberhq.atlassian.net/browse/AI-1284): the PoC requirements.
- [The spec doc](https://claude.ai/artifact/USQaoApiwWgHhxZCJmGa9H).
- [The Amber Helpdesk design](https://claude.ai/artifact/MzabbXfEeu8iHWcDo5s2Tg).

New planning docs go in this folder. Give each file a name that says what it covers, for example `starter-tickets-sprint-2.md`.
